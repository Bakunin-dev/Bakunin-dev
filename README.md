## Есть цель. Нужна техническая реализация.

| «Нужен LLM-пайплайн» | «Нужно связать сервисы» | «Нужно проверить качество» |
| :--- | :--- | :--- |
| Есть сценарий и примеры результата. Нужно выбрать подход и собрать обработку данных с помощью модели. | Нужны API, коннекторы и серверная логика, чтобы данные проходили через согласованный сценарий. | Нужно сравнить подходы на примерах, разобрать ошибки модели и обозначить ограничения решения. |
